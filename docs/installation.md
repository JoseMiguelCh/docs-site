# Installation

Pocket Timer installs with one command on macOS, Linux and Windows.

## Requirements

You need `pipx` installed on your system. Pocket Timer is installed through it.

## macOS

Run `pipx install pocket-timer` in your terminal.

## Linux

Run `pipx install pocket-timer` in your terminal.

## Windows

Run `pipx install pocket-timer` in your terminal.

## Verify the installation

Run `pocket --version`. It prints the installed version of Pocket Timer.
